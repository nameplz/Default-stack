# explore

릴리스마다 검증 스킬의 기능 지도대로 앱을 직접 실행해 탐색하고, 재현된 버그마다 수정 PR을 따로 올려 자동 병합한다.

실행 절차는 [references/explore.md](../../../../plugin/references/explore.md).

## 흐름

1. 대상은 최신 릴리스 태그(없으면 기본 브랜치 HEAD). 주기 실행은 사용자가 호스트 스케줄러로 건다.
2. 기능별 여정을 끝까지 실행하고 경계(빈 입력, 취소, 리사이즈, 백엔드 실패, 재시작)를 민다. 증거를 남긴다.
3. 두 번 재현된 버그만 고친다. 재현 안 됨·제품 판단 필요는 보고만, 지도에 없는 여정은 지도에 추가.
4. 버그마다 기본 브랜치에서 브랜치 → 실패 테스트 → 근본 원인 수정 → `verify` → [ship-it](ship-it.md). 실행당 PR 최대 5개.
5. 보고는 `work/explore/<date>.md`.
