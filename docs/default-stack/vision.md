# Vision

막연한 아이디어를 대화로 구체화하고, 저장소를 "지침이 아니라 검사가 에이전트를 붙잡는" 상태로 만들어 필수 검사만 통과하면 변경이 스스로 병합되게 하는 개인 워크플로 플러그인. 저장소 쪽은 Lauren Tan의 방식을 따른다.

## 대상

- 아이디어 구상 단계인 프로젝트 초기 (coffee-chat)
- 검증 기반을 갖추고 자동 병합으로 운영할 저장소 (apply-stack 이후)
- 소~중규모 개인 프로젝트

## 배포

- Claude Code와 Codex 양쪽에서 동작하는 플러그인
- 마켓플레이스로 공유

## 핵심 원칙

- **가볍게 시작, 구조화는 나중에**: 대화는 자유롭게, 구조는 문서 저장 시점에만 적용한다.
- **검사가 게이트**: 반복되는 실수는 지침이 아니라 구조·검사로 막고, 사람 리뷰 대신 필수 검사로 병합한다.
- **필요 최소한**: 문서도 코드도 필요한 만큼만 만든다. 오버 엔지니어링 금지.
- **증거 기반 판정**: 확인한 것과 확인하지 못한 것을 구분한다.
- **맥락 복원**: 이후 세션에서도 문서만으로 맥락을 되살릴 수 있게 한다.
